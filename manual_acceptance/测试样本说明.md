# 测试样本说明

样本位于 `samples/manual_acceptance/`，均为独立、固定且可重复导入的 JSON。

| 文件 | 输入状态 | 预期 | 用途 |
|---|---|---|---|
| 01_normal_epic_plus0.json | 普通红 +0 | 轻量预测 | 基础早期导入 |
| 02_normal_epic_plus3.json | 普通红 +3 | 轻量预测，继续至 +6 | 早期速度命中，走早期赌速度路线 |
| 03_normal_epic_plus6_speed.json | 普通红 +6、一跳速度 | 精确 DP，继续；回放至 +15 为转换/过渡 | 后续固定回放与建议变化 |
| 04_rift_epic_plus0.json | 异界红 +0 | 轻量预测 | 红装锁定和异界跳值 |
| 05_legacy_reforge_false.json | 旧 85 JSON | 导入/保存后默认可重铸 | 兼容性 |
| 06_invalid_rift_heroic.json | 异界紫装 | 明确拒绝 | 错误态 |
| 07_high_speed_early.json | 高速度 +3 | 轻量预测高确定性继续 | 高确定性速度胚子 |
| 08_normal_heroic_plus9_replay.json | 普通紫 +9 | +12 补第 4 条 | 紫装固定回放 |
| 09_speed_boot_output_full.json | 速度主属性鞋，完整输出 | 轻量预测直接继续 | 速度鞋输出例外 |
| 10_speed_boot_tank_full.json | 速度主属性鞋，完整坦克 | 轻量预测直接继续 | 速度鞋坦克例外 |
| 11_attack_boot_with_speed.json | 攻击%鞋带速度副属性 | 不得走速度保护路线 | 非速度鞋排除路线 |
| 12_attack_boot_output_no_speed.json | 攻击%鞋、无速度、完整输出分类 | 轻量预测待 +6 精确复核 | 非速度低速输出鞋按分组校准，不以完整命中直接继续 |
| 13_health_boot_tank_no_speed.json | 生命%鞋、无速度、完整坦克分类 | 轻量预测待 +6 精确复核 | 非速度低速坦克鞋按分组校准，不以完整命中直接继续 |
| 14_mixed_categories_no_full_match.json | 副属性混合、无法完整命中 | 轻量预测待 +6 精确复核 | 不得把不同分类的有效属性拼接为完整胚子 |

轻量预测 debug 必须含完整分类与逐项命中诊断、校准分组和门槛、理论上下界、预期重铸有效分、预期速度、速度门槛概率和跨档概率；`dp_decision` 会明确标注 `lightweight_continue/review/stop`，表示尚未运行精确 DP。精确 DP 必须显示 `exact_dp` 与效用。

08 紫装样本当前为 +9、3 条副属性；需打开验收强化回放并点击下一次强化，才验证 +12 补第 4 条词条。
