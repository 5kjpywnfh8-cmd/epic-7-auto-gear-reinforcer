# normal_85 Heroic 资源重校准只读审计（2026-07-11）

## 结论

结论分类为 **B. 校准噪声**：`8648.1` 可由当前实现稳定复现，但不是可发布的 `normal_85 Heroic` DP 常量。它来自单一 seed、仅 6 个非零终局样本的比值；两个独立 seed 分别给出 `8729.1` 与 `15768.7`。此外，当前材料实现与随后确认的“下级强化石/经验粉末按基础经验 50/50 混合”规则不符（独立的资源口径偏差），因此在修复并重校准前不得继续使用当前 Heroic lambda。

本轮只读审计；仅新增本报告并更新计划文档。未修改 `.py`、JSON 配置、测试、GUI、既有报告或既有校准产物。

## 计算链路

```text
维度裂缝 Heroic 毛胚子 23.81
  - 宠物下级石信用 1.2713179953
  = 净胚子 22.5386820047 体力/件
  + 强化消耗 - 停止时出售回收
  = 每条模拟的 net stamina
  -> 10,000 条求和 total_stamina
  / 成功终局的正式百里分 total_baili_score
  = cost_per_baili_score
  -> DP_ASSIST_CONFIGS 中 lambda = 1 / 已发布的四舍五入 cost
  -> route_solver: terminal_value - lambda * incremental_stamina
```

直接实现位置：

- [calibration.py](../src/e7_enhance/calibration.py:1920) 定义 `cost_per_baili_score = total_stamina / total_baili_score`。
- [calibration.py](../src/e7_enhance/calibration.py:337) 定义 DP `lambda = 1 / cost`；[calibration.py](../src/e7_enhance/calibration.py:112) 发布当前 `8648.1`。
- [enhance_simulator.py](../src/e7_enhance/enhance_simulator.py:313) 的 `cost_for_outcome` 以胚子、累计强化与出售回收形成每条净成本。
- [route_solver.py](../src/e7_enhance/route_solver.py:241) 将节点材料边际成本乘 `lambda`；转换石只在终局转换路径扣除，见 [route_solver.py](../src/e7_enhance/route_solver.py:313)。

`1 / 8648.1 = 0.0001156323354`，与发布值 `0.00011563` 一致。复现的未四舍五入比值为 `233497.4513805 / 27.0 = 8648.0537548`，其倒数为 `0.0001156329538`；两者差异仅来自发布前将 cost 四舍五入到一位小数。

固定参数均为：`normal_85`、`Heroic`、`riftslash_20_buff`、`baili_marginal_low`、10,000 件、4 workers。临时 JSON 仅保存在系统临时目录，未写入工作区。

正式发布值准确复现，但三次的范围为 `8,648.05 - 15,768.69`（相对最低值约 +82.3%）。总成本的三次差异不足 0.25%，分母从 `27.0` 降到 `14.8` 才造成波动。

各 seed 的终局百里分均值分别为 `0.00270 / 0.00268 / 0.00148` 每件；中位数均为 `0`，非零率均为 `0.06%`。这不是分母为零，但已接近“极少数样本主导比值”的状态。

### seed 20260711 分子与分母

```text
total_stamina = 225,386.82（胚子）
              + 17,033.89（强化）
              -  8,974.25（出售回收）
              = 233,497.45

cost_per_baili_score = 233,497.45 / 27.0 = 8,648.05
```

`+0/+3/+6/+9/+12/+15` 停止数依次为 `9877 / 37 / 16 / 21 / 34 / 15`。仅 `15` 件实际到达 `+15`；其中策略成功 6 件，原生成功 1 件、转换救回 5 件。无路线在分母为零时被发布，但 99.94% 样本的终局百里分为零。

最终 `+15` 状态中正式分类命中数为 `4`（其中有些没有被 `baili_marginal_low` 路线保留）；最终原生成功同为 `4`。策略路径成功数为 `6`，原因是转换救回也能作为正式终局价值进入分母。转换石成本并未遗漏：把每次转换固定加上 100,000 金币等价后，该 seed 的成本从 `8648.1` 变为 `8651.1`。

## 已确认的材料口径偏差

当前 [resource_model.py](../src/e7_enhance/resource_model.py:195) 的 `material_cost_for_level` 只创建粉末单位；[resource_model.py](../src/e7_enhance/resource_model.py:185) 又把来源下级石当作“替代一整批粉末”的胚子信用。两者没有实现已确认的“按基础强化经验 50% 下级石 + 50% 粉末”组合，因此当前实现确实将两种材料作为二选一路径。

按现有逐级期望成本约定，在临时诊断中对每一级先分配 `nominal_exp / (2 * 1.15395)` 的两种基础经验，再分别向上取整到 1,500/100 单位，并对整个混合批次计算 Good/Great 与 100 经验粉末溢出回收。紫装区间成本从当前全粉末变为：

| 区间终点 | 当前全粉末 金币 / 净经验 | 临时 50/50 金币 / 净经验 |
|---:|---:|---:|
| +3 | 28,800 / 1,646.0 | 59,200 / 1,021.5 |
| +6 | 62,400 / 3,586.5 | 76,800 / 3,411.5 |
| +9 | 139,200 / 8,023.5 | 129,600 / 8,298.0 |
| +12 | 270,400 / 15,580.0 | 236,800 / 16,450.0 |
| +15 | 536,000 / 30,871.0 | 441,600 / 31,912.5 |

在同一 seed 20260711 的相同 10,000 条路径上，临时 50/50 方案为 `8661.12`，比当前 `8648.05` 高 `0.15%`。它不是十倍差异的原因，但必须修复后才能重发正式 Heroic 参数；同时需要明确“来源额外下级石”如何与固定 50/50 消耗池结算，避免再次把同一石头同时当作库存比例和胚子信用。

## 与旧 280.3 的比较

旧资源报告明确说明 `280.3` 是“仅强化路径、紫装胚子成本未确认”的暂定值，故其分子不含每件胚子成本。以现行路径、同一 seed、只把胚子改为 0 的可比重放结果为 `300.39`，接近旧 `280.3`，证明数量级差异主要来自口径变化。

旧值的原始 JSON、具体随机 seed、未四舍五入总成本和终局百里分未保留；仓库只有单一初始 git 提交，无法再精确还原 `280.3` 的 7% 差额。因此不得把 `280.3` 与 `8648.1` 当作同口径回归，也不得以二者差异单独判定代码回归。

## 是否允许继续使用当前 lambda

不允许将 `0.00011563` 作为稳定默认 Heroic DP lambda 使用：

1. 单一 seed 的非零样本只有 6，三 seed 范围达 82.3%，当前 `8648.1` 是噪声敏感的点估计。
2. Heroic 使用 `baili_marginal_low`，Epic 使用 `category_baili_marginal_mid`，两者不是相同基础策略；不能仅凭 10 倍差异判断品质成本异常。
3. 50/50 材料组合尚未进入正式资源模型，现有下级石信用与该口径需要一并重新定义。
