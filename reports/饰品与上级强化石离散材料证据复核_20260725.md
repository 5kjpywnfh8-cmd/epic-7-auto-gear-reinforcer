# 饰品与上级强化石离散材料证据复核

## 结论

- 当前规划器把整个饰品池标记为 `unsupported_material`，根因不是游戏没有数据，而是离线规划器任务漏审了仓库内已跟踪的 batch `013` 强化页截图。
- 饰品强化粉末与下级饰品强化石已经具备可追溯离散证据：基础经验分别为 `100`、`1,500`，使用金币分别为 `1,600`、`14,400`。这与当前普通材料常量一致，但材料池身份仍必须独立保留。
- 上级饰品强化石的 `4,500` 基础经验由截图直接显示；用户此前提供的权威消耗表记录上级强化石使用金币为 `43,200`，并于 `2026-07-25` 明确澄清该表同时适用于装备与饰品强化石，只是适用部位及材料池不同。因此上级饰品石发布常量为 `4,500 EXP / 43,200` 金币，不再因金币证据 fail closed。
- `13:5` 是此前用户确认的日常材料总量近似，`1.3` 是按服务部位数归一化后的相对机会成本。它们不是单个饰品材料的经验或金币数据，也没有当前仓库内的原始获取日志支撑进一步拆分。
- 本轮只更正证据结论，不修改代码。规划器当前仍会拒绝饰品请求；启用饰品粉末/下级石需要独立代码修复任务和回归测试。

## 基础经验与预览经验

材料列表直接显示的是基础经验：`100 / 1,500 / 4,500 / 13,500`。选择预览显示：

| 组合 | 基础经验合计 | 界面预览经验 | 金币 |
|---|---:|---:|---:|
| 下级石 1 | 1,500 | 1,749 | 14,400 |
| 下级石 1 + 粉末 1 | 1,600 | 1,865 | 16,000 |
| 下级石 1 + 粉末 2 | 1,700 | 1,982 | 17,600 |

三组界面预览均精确符合 `floor(基础经验 * 1166 / 1000)`：`1,500 -> 1,749`、`1,600 -> 1,865`、`1,700 -> 1,982`。用户确认宠物提供 `+6.6%`，并授权当前账号离线执行预算直接使用页面已验证的总倍率 `1.166`。该总倍率还包含页面基线中的另外 `+10%`，因此不能将其描述为仅由宠物 `+6.6%` 单独产生。

`1.166` 是当前账号页面基础倍率，执行预算先按 `floor(基础经验 * 1.166)` 取整，并要求实际执行前用新鲜页面预览复核。Good/Great 的随机层期望应再叠加 `0.89*1 + 0.055*1.5 + 0.055*2 = 1.0825`；不能把旧的 `1.15395 = 1.0825*1.066` 直接当作最终倍率，因为它漏掉页面基础 `+10%`，且将宠物倍率重复混入。页面预览不符合整数规则时仍须 fail closed。

## 获取数据现状

- 已有：用户确认的日常通用材料与饰品材料总量近似 `13:5`。
- 已有：按服务部位 `4:2` 归一化得到饰品材料机会成本系数 `(13/4) / (5/2) = 1.3`。
- 已有：batch `013` 操作时点的库存快照 `23,353 / 514 / 201 / 214`。
- 缺失：`13:5` 的原始日期、来源、逐日样本、材料分级构成和波动区间。
- 已有：用户权威消耗表及本轮适用范围澄清确认上级饰品石 `4,500 EXP / 43,200` 金币；不再要求重复单独选择才能用于离线预算。
- 缺失：传说石单独选择时的金币预览与实际消耗闭环；传说石仍不在当前规划器范围。
- 执行边界：`1.166` 已获准用于当前账号离线预算；资源期望在该整数页面结果上叠加随机层，但每次实际执行仍需新鲜页面预览验证稳定性。

因此，`1.3` 可继续用于研究中的相对机会成本，但不能替代离线执行规划所需的整数经验和金币常量；库存快照也不能当作日常获取率。

## 对当前规划器的影响

`offline_budget_planner.py` 当前将 `accessory_powder`、`accessory_lower_enhance_stone` 的经验和金币都设为 `None`。这与现有已跟踪证据不再一致，属于安全但过度保守的支持缺口。

后续独立修复任务应至少：

1. 用截图、权威消耗表及用户澄清固定两类材料池的粉末、下级石和上级石常量，并保持材料池隔离。
2. 补两个材料池、三种材料、五段节点、库存与硬上限的同等回归矩阵。
3. 当前账号按整数规则 `floor(基础经验 * 1166 / 1000)` 规划有效经验，并输出基础经验与有效经验；实际执行前用新鲜页面预览复核。
4. 按 `floor(基础经验 * 1.166)` 建立页面基础结果，再叠加随机层 `1.0825`；旧 `1.15395` 不再作为单一最终倍率。

本报告不构成模拟器操作、材料选择、资源消耗或代码修改授权。
