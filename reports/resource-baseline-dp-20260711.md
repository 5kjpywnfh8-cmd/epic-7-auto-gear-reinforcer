# 资源成本基线与 DP 重校准（2026-07-11）

## 已采用基线

- 圣女 3-7：每 8 体力 `58,889.177` 金币、`1,161.1` 基础强化经验。
- 强化粉末：每份 `100` 基础经验、`1,600` 金币；强化石预设未启用。
- Good / Great 互斥，概率均为 `5.5%`，倍率分别为 `1.5` / `2.0`；宠物强化经验 `+6.6%`。
- 期望强化经验倍率：`1.15395`。
- 默认红装胚子：一刀龟裂 Buff，`85` 体力/件。
- 转换：`100,000` 金币，经同一资源模型折算为体力，不再传递无单位体力常量。

## 材料模型

每个 `+1` 逐级经验独立计算粉末批次：

```text
粉末数 = ceil(标称经验 / (100 * 1.15395))
批次金币 = 粉末数 * 1,600
期望返还粉末 = sum(概率 * floor(max(0, 批次经验 * 结果倍率 - 标称经验) / 100) * 100)
净基础材料经验 = 投入粉末经验 - 期望返还粉末
```

Good / Great / 宠物不会改变已支付的强化金币。金币与基础材料经验由同一副本产出时，体力等价取两者的瓶颈，不相加。
