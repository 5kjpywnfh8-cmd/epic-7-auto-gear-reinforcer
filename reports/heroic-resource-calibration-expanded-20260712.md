# normal_85 Heroic 扩展资源校准（2026-07-12）

## 结论

`normal_85 Heroic` **仍不能发布独立资源 lambda**。本轮累计 45 个独立 seed、450,000 条模拟和 206 个非零终局，已经达到数量门槛；但 95% 置信区间相对半宽为 `39.32%`，远高于 `10%`。后半样本相对偏差 `0.97%` 合格，但不能抵消区间不合格。

在同一 45 个 seed、同一轨迹上，维度裂缝 Heroic 毛胚子 `23.81` 的 `+/-20%` 使候选 lambda 在基线两侧变化 `+26.90% / -17.49%`。`23.81` 仍是 `estimated`，所以即使未来统计 CI 通过，亦应先补强该来源证据或以明确的保守区间审核候选常量。

未更新 `DP_ASSIST_CONFIGS`，未发布 lambda，未恢复 `8648.1 / 0.00011563 / 0.00356761`。当前保持 `baili_marginal_low` 回退；`+0/+3` 轻量预测继续可用，`+6` 后不使用未发布资源 lambda。

## 校准工具

`tools/recalibrate_resource_dp.py` 原先只能一次性运行三个配置，并在全部完成后写文件。本轮仅扩展该工具：

- `--configs normal_85_heroic` 可只跑 Heroic；
- `--resume-existing <json>` 可复用已有 seed 行；
- 重复 seed（批内或恢复文件中）明确拒绝；
- 每个完成 seed 原子保存，后续失败不会丢失已有结果；
- `--heroic-gear-stamina` 只用于进程内敏感性覆盖，不写回资源模型或配置。

敏感性覆盖首次在低样本串行路径有效、在 10,000 条多进程路径丢失。根因是 Windows 子进程重新导入模块，不继承父进程的临时来源覆盖。工具现在在敏感性模式下按 seed 外层四进程并行，并在各子进程内部以单线程校准，让覆盖进入真实成本记账；普通校准仍维持原有内部四 worker 路径。回归测试覆盖了该跨进程行为。

## 合并结果

固定参数：`normal_85` / `Heroic` / `baili_marginal_low` / `riftslash_20_buff`，每 seed 10,000 条、4 workers。正式估计始终是：

```text
cost_per_baili_score = sum(total_stamina) / sum(terminal_baili_score)
lambda_candidate = 1 / cost_per_baili_score
```

| 项目 | 结果 |
|---|---:|
| seed | 45（20260711-20260824） |
| 总模拟量 | 450,000 |
| 合并总成本 | 10,108,477.7297 体力 |
| 合并终局百里分 | 787.6 |
| 非零终局数 | 206 |
| 候选 cost | 12,834.5324 体力/百里分 |
| 候选 lambda | 0.0000779147980 |
| 95% 相对半宽 | 39.3209% |
| 后半样本偏差 | 0.9652% |

发布门槛：非零终局 `>=200` 为通过；CI `<=10%` 为不通过；后半偏差 `<=10%` 为通过。综合为 **不发布**。

现有 seed 比值的波动仍由稀少且分值不均匀的有效终局主导。若假设当前独立 seed 方差和 `1/sqrt(n)` 收敛关系不变，要把相对半宽从 `39.32%` 压到 `10%`，约需 696 个同规模 seed，即约 6.96M 模拟（还需约 6.51M）。这是规划估算，不是通过保证；不能挑选 seed 或跳过低分批次。

原始合并结果：[heroic-resource-calibration-expanded-20260712.json](heroic-resource-calibration-expanded-20260712.json)。

## 23.81 敏感性

三组均使用同一 45 个 seed，因此终局百里分 `787.6`、非零终局 `206` 完全相同；只有资源成本分子发生变化。

敏感性原始结果：[减 20%](heroic-resource-calibration-sensitivity-minus20-20260712.json)、[加 20%](heroic-resource-calibration-sensitivity-plus20-20260712.json)。它们没有写回默认来源成本。

对 16 件固定真实 Heroic 验收样本，以三个成本情景分别计算前台建议、目标体系、下一节点和轻量决策，变化数均为 `0`。原因是 Heroic 当前明确未发布资源校准，所有样本均走基础策略/轻量策略，而非 DP lambda 路线；这不是敏感性已安全的证明。若未来要发布 Heroic lambda，当前来源成本不确定性会让候选数值跨约 54% 的全范围，必须单独复核临界建议。
